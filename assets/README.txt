Place your local website images inside this 'assets/' folder.
Examples:
- assets/logo.png
- assets/hero-mahakal.jpg
- assets/swift-dzire.jpg
- assets/ertiga.jpg
- assets/innova.jpg
- assets/tempo.jpg
- assets/omkareshwar.jpg

Then update the image path in 'site-config.js' (for example: image: 'assets/swift-dzire.jpg') and push to GitHub.
